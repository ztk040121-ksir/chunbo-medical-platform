## 二、测试步骤

### 测试 1：云诊所（图片病因分析 + RAG）

- **地址**：http://localhost:5173 ，登录 `kzt / 123456`
- **步骤**：
  1. 进入「AI 临床助手」标签页
  2. 点输入框旁的 🖼 上传按钮，选择 `clinic/湿疹皮疹-发病部位测试图.png`
  3. 看到图片预览后，输入：`请根据这张图片分析患者的病因`
  4. 点发送
- **预期结果**：AI 识别出皮肤病灶特征（红色丘疹 / 湿疹样皮疹），自动调用 RAG 知识库比对临床规范，给出**病因分析 + 鉴别诊断 + 就诊建议**，并说明"仅供医生参考、需面诊确认"。

### 测试 2：OA 中台（工资表发工资）

- **地址**：http://localhost:5174 ，登录 `admin / 123456`
- **步骤**：
  1. 在 AI 指令输入框旁点 📎 上传按钮，选择 `oa/工资表-2026年9月.xlsx`
  2. 看到文件名预览后，输入：`这是2026年9月的工资表，请按表格给员工发工资`
  3. 点「发送指令」
- **预期结果**：AI 提取表格（康主任 / 张文浩 / 王商户 及其工号、金额），逐个调用发工资工具匹配员工档案，回复汇总结果。可在数据库验证：
  ```sql
  SELECT doctor_id, doctor_name, salary_month, net_salary, status
  FROM oa_salary_slip ORDER BY id DESC LIMIT 3;
  ```
  （应出现 2026-09 月的"已发放"记录）

### 测试 3：春播商城（药品图识别 + 下单卡片）

- **地址**：http://localhost:5175 ，游客无需登录
- **步骤**：
  1. 在咨询输入框旁点 🖼 上传按钮，选择 `mall/布洛芬药盒-测试图.png`
  2. 看到图片预览后，输入：`这个药商城有吗`
  3. 点「咨询药师」
- **预期结果**：AI 识别出药品（布洛芬），调用查库存工具，返回药品信息 + **带价格的下单卡片**（`recommendations`）。

## 三、注意事项

1. **图片为 AI 生成的示意图**，非真实病例/真实药盒，仅用于功能流程测试，不构成任何医学依据。
2. **测试 2（发工资）会真实写入数据库** `oa_salary_slip` 表，测完如需清理，删除对应测试月份记录即可。
3. 若图片识别返回"AI 服务调用异常"，通常是中转站模型额度/网络问题，检查后端日志确认。
4. 测试图片也可换成你自己的真实照片（清晰、光线充足效果更好）。
