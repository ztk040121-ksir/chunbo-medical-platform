## 2. 缺陷闭环与排查 SOP
1. **Token 消耗异常暴增**：
   - 检查 ChatMemory 历史会话长度，设置 `maxMessages = 10` 截断防止上下文膨胀。
2. **工具参数解析偏差**：
   - 使用 `@ToolParam` 严格约束参数语义与格式（如 yyyy-MM），减少大模型幻觉。
3. **数据库事务一致性**：
   - 审批状态变更与日志写入使用 Spring `@Transactional`，杜绝孤儿数据。
