# 基层皮肤科常见病诊疗规范（皮损识别与用药指南）

## 带状疱疹诊断与治疗规范
- 典型皮损：单侧、沿单一神经节段呈带状分布的成簇小水疱，疱液清亮，基底鲜红，伴明显神经痛/灼痛/针刺痛，出疹前常有前驱疼痛。
- 诊断标准：簇集性水疱 + 单侧带状分布 + 神经痛三联征即可临床诊断，无需特殊检查。
- 规范治疗方案：早期（出疹72小时内）口服**阿昔洛韦片**，一次0.8g，一日5次，疗程7天（72小时黄金抗病毒窗口，越早越好）；疱疹未破瘙痒明显者外用**炉甘石洗剂**摇匀涂擦，一日2-3次；皮损继发细菌感染（脓性分泌物）外用**莫匹罗星软膏**一日3次。
- 用药安全警戒：阿昔洛韦经肾排泄，肾功能不全者必须减量；疱疹眼部受累、皮损广泛、免疫低下患者立即转诊上级医院。

## 接触性皮炎诊断与治疗规范
- 典型皮损：手背、面部等暴露部位边界较清楚的红斑，其上密集针尖至粟粒大小水疱，剧烈瘙痒，发病前24-72小时有染发剂、金属（镍）、橡胶手套、洗涤剂、水泥等可疑接触史。
- 诊断标准：接触史 + 皮损范围与接触部位一致 + 边界清楚；反复发作或病因不明者做斑贴试验明确过敏原。
- 规范治疗方案：立即停用可疑接触物并清水冲洗；外用**丁酸氢化可的松乳膏**薄涂一日2次（短期，不超过1周）；瘙痒明显口服**氯雷他定片**10mg一日1次；渗出糜烂期先用生理盐水冷湿敷，勿直接涂膏。
- 用药安全警戒：糖皮质激素外用不宜长期大面积使用；面部及皮肤薄嫩部位慎用；询问既往药物过敏史（青霉素/头孢/磺胺）。

## 急性湿疹与汗疱疹诊断与治疗规范
- 典型皮损：手部对称分布的深在性针尖至米粒大小水疱，手掌侧缘、手指侧面多见，伴剧烈瘙痒与脱屑，可反复发作。
- 鉴别要点：汗疱疹多对称分布于手掌侧缘；带状疱疹为单侧沿神经走行且伴疼痛；接触性皮炎有明确接触史且边界清楚。
- 规范治疗方案：口服**氯雷他定片**10mg一日1次抗过敏止痒；外用**丁酸氢化可的松乳膏**短期控制炎症；继发感染（脓性渗出）联合**莫匹罗星软膏**一日3次。
- 用药安全警戒：避免接触洗涤剂、热水烫洗及机械摩擦；激素药膏症状缓解后即减停，勿长期使用。

## 手癣与足癣（真菌感染）诊疗规范
- 典型皮损：单侧手/足红斑脱屑，边缘呈环状向外扩展，可有水疱或角化增厚，瘙痒；多同时伴有足癣（脚气）病史。
- 诊断标准：皮损边缘刮取鳞屑做真菌镜检/培养阳性是金标准；"一手两足"（单手+双足）分布高度提示真菌感染。
- 规范治疗方案：外用**酮康唑乳膏**涂于患处及周围正常皮肤，一日2次，疗程2-4周，症状消失后继续用药1-2周防止复发。
- 用药安全警戒：真菌感染严禁单用糖皮质激素药膏（会抑制局部免疫、加重感染）；角化过度型需联合口服抗真菌药时，须评估肝功能并转诊。

## 荨麻疹诊疗规范
- 典型皮损：风团（隆起性苍白或红色风团块）时起时消、剧烈瘙痒，单个风团24小时内自行消退，消退后不留任何痕迹。
- 诊断标准：风团 + 剧痒 + 24小时内消退不留痕即可诊断；需追问食物、药物、感染等诱因。
- 规范治疗方案：首选**氯雷他定片**10mg一日1次；局部瘙痒外用**炉甘石洗剂**摇匀涂擦。
- 用药安全警戒：出现胸闷、喉头发紧、呼吸困难、面色苍白等喉头水肿/过敏性休克征象，立即肾上腺素肌注并转急诊；常规治疗无效或反复超过6周者转诊查过敏原。

## 脓疱疮（黄水疮）诊疗规范
- 典型皮损：红斑基础上迅速出现薄壁脓疱，破溃后形成蜜黄色厚痂，好发于面部、口周、手部等暴露部位，儿童多见，有接触传染性。
- 诊断标准：蜜黄色厚痂 + 浅表脓疱 + 好发年龄季节即可临床诊断。
- 规范治疗方案：外用**莫匹罗星软膏**一日3次，疗程7天；用药前可用生理盐水或75%酒精消毒液轻拭去痂；皮损泛发、伴发热或淋巴结炎者加用口服**阿奇霉素颗粒**（青霉素过敏者可用）。
- 用药安全警戒：注意隔离消毒（毛巾衣物分开）防止传染；出现血尿、眼睑水肿等肾炎样表现立即转诊。

## 皮肤病皮损视诊与鉴别要点（通用）
- 视诊顺序：先定部位（暴露/遮盖、单侧/对称），再定皮损性质（红斑/水疱/脓疱/风团/鳞屑），最后看分布形态（簇集/带状/环状/散在）。
- 单侧簇集水疱 + 疼痛 → 首先考虑带状疱疹（警惕72小时抗病毒窗口期）；对称分布小水疱 + 剧痒 → 考虑湿疹/汗疱疹；边界清楚 + 有接触史 → 考虑接触性皮炎；蜜黄色痂 → 脓疱疮；环状边缘扩展脱屑 → 真菌感染。
- 红线：皮肤病诊断依赖视诊+触诊+病史，图片辅助分析仅供执业医师参考，最终诊断必须医生面诊确认；外用药前必须核对患者药物过敏史。
