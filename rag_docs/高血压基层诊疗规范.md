# 基层医疗原发性高血压诊疗与处方规范指南

## 一、 临床表现与分级诊断
1. **典型主诉**：头晕、眼花、头胀、后颈部紧绷沉重感、易疲劳、失眠、耳鸣。
2. **血压分级标准**（非同日3次静息坐位测定）：
   - 正常血压：收缩压 < 120 mmHg 且 舒张压 < 80 mmHg。
   - 1级高血压（轻度）：收缩压 140～159 mmHg 和/或 舒张压 90～99 mmHg。
   - 2级高血压（中度）：收缩压 160～179 mmHg 和/或 舒张压 100～109 mmHg。
   - 3级高血压（重度）：收缩压 >= 180 mmHg 和/或 舒张压 >= 110 mmHg。

## 二、 规范用药路径与用药禁忌
1. **一线推荐长效降压药物**：
   - **钙通道阻滞剂（CCB）**：首选**苯磺酸氨氯地平片**（5mg qd）。优势在于降压平稳、抗动脉粥样硬化、无绝对禁忌证，适合老年高血压及高血压合并动脉硬化。
   - **血管紧张素II受体拮抗剂（ARB）**：首选**缬沙坦胶囊**（80mg qd）。对靶器官（肾脏、心脏）有良好保护作用，适合高血压合并糖尿病或微量蛋白尿患者。
2. **用药安全警戒**：
   - 缬沙坦等 ARB 药物**严禁用于妊娠期妇女**及双侧肾动脉狭窄患者。
   - 氨氯地平长期服用偶见下肢踝部轻度水肿，可向患者解释无需恐慌。
   - 对 2 级以上高血压或单药控制不理想者，指南推荐联合方案：CCB（氨氯地平） + ARB（缬沙坦）联合服用。
