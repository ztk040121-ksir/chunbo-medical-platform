# 基层2型糖尿病用药规范与安全指导原则

## 一、 诊断依据与筛查
- 空腹静脉血浆葡萄糖（FPG） >= 7.0 mmol/L。
- 糖化血红蛋白（HbA1c） >= 6.5%。
- 伴有口渴多饮、多食、多尿、不明原因体重下降。

## 二、 药物治疗路径
1. **一线首选降糖基石药物**：
   - **盐酸二甲双胍缓释片**：初始剂量 0.5g 每日两次（bid），随餐服用。双胍类可增加外周组织对胰岛素敏感性，抑制肝糖原异生，不刺激胰岛素分泌，单用极少发生低血糖。
2. **用药安全警示**：
   - 肾功能不全者（估算肾小球滤过率 eGFR < 45 ml/min）需停用或减量，警惕乳酸酸中毒风险。
   - 初始服药可能出现恶心、腹泻等胃肠道轻度反应，餐中服用可显著改善。
