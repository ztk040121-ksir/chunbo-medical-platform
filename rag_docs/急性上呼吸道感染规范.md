# 基层急性上呼吸道感染鉴别与抗生素规范使用指南

## 一、 鉴别诊断要点
1. **普通感冒（多数为病毒感染）**：喷嚏、流涕、咽痛明显，多无发热或仅轻度发热，白细胞计数正常或偏低。**切忌滥用抗生素！**
2. **急性咽扁桃体炎/细菌性上感**：咽部扁桃体肿大充血、有黄白色脓性渗出物，伴高热（体温 > 38.5℃）、下颌下淋巴结肿大压痛，血常规 WBC 与 CRP 显著升高。

## 二、 规范用药与强红线
1. **对症退热镇痛**：体温 >= 38.5℃ 时选用**布洛芬缓释胶囊**（0.3g），间隔 8-12 小时。
2. **细菌感染抗菌药物选择**：
   - 首选口服青霉素类：**阿莫西林克拉维酸钾片**。
   - **绝对红线**：开立处方前**必须强行校验患者药物过敏史**！凡明确记录【青霉素过敏】者，**严禁开具阿莫西林**！
   - 若患者有青霉素过敏史，应替代评估大环内酯类或严格排查是否可使用三代头孢（需注意交叉过敏评估）。
