# 春播商城多智能体协同运营与交付 SOP 规范

## 1. 角色差异化推荐话术准则
1. **诊所主任 / 主治医师 (Director)**：
   - 核心诉求：临床疗效、患者依从性、特色专科技术壁垒；
   - 推荐要点：强调中药配方道地性、透皮渗透吸收机理、立竿见影的临床痛点解决能力。
2. **采购经理 / 商务主管 (Buyer)**：
   - 核心诉求：进销差价、阶梯返利、区域控销保护（防倒挂倾销）；
   - 推荐要点：强调独家一镇一店保护政策、起批阶梯折扣（满300盒9折、满500盒85折）、账期扶持。
3. **门诊客服 / 药事顾问 (CS)**：
   - 核心诉求：首营资质完备、物流破损包赔、退换货无忧；
   - 推荐要点：强调 GSP 随货同行单、COA 报告、冷链次日达、季节性贴敷季末 100% 退换货保障。

## 2. 状态机分发异常与降级 SOP
- 若用户提问兼具“既要问资质，又要谈价格”，Router 采用优先满足议价计算、末尾附带资质提示的双链协同模式，避免死循环。
